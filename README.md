# Study Indian Stock Market

A web application for learning and tracking the Indian stock market, styled with a classic **VB6 / Windows 98** look-and-feel.

## Features

- **VB Classic menu bar** — File · View · Market · Analysis · Tools · Help  
- **Toolbar** — quick-access icon buttons  
- **MDI workspace** — draggable inner windows  
- **Market Overview table** — key indices (Nifty 50, Sensex, Bank Nifty, …)  
- **Quick-links panel** — one-click navigation  
- **Status bar** — live clock

## Getting Started

Open `index.html` directly in any modern browser — no build step required.
